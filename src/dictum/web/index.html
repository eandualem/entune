Get started

Three steps, and every dictation lands here as text you can copy.

    The file is dictionary.json in Dictum's data folder. Replacements are whole words, matched regardless of case; the longest phrase wins.
    WordA name or term the speech model should expect: Dictum, CLAUDE.md. Sent to the model before it listens. ReplacementWhat it heard → what you meant, fixed in every transcript afterwards: cloud code → Claude Code. PinnedEntered by you. Used with every model. Never changed by a machine. LearnedProposed from one model's own transcripts and accepted by you. Used only with that model.
    RefineSends this model's recent transcripts, with your pinned list as context, to the dictionary model set in Settings. You get a proposal, entries to add and to drop, and nothing is saved until you press Accept. AgentsAgents you dictate to can post a confirmed correction to Dictum's local API. It arrives here as Pinned; remove it if they got it wrong. LimitsEvery provider caps how many words it takes; Parakeet takes none and uses replacements only.
