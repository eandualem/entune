Get started

Three steps, and every dictation lands here as text you can copy.

    The file is dictionary.json in Dictum's data folder. Forms match whole words regardless of case. Context resolves eligible meanings and overlapping phrases.
    GroupRecognized forms linked to possible meanings. For cloud, Claude and a literal cloud can compete; Jev chooses the meaning and Dictum applies its stored spelling. MeaningA general definition, optional personal usage, and exact output spelling. Valid decisions select the highest-scoring eligible meaning, even when scores are close. Missing usable definitions are left unresolved. PinnedShared with every model and protected from builds. Pinning shares all variants; reviewed definition updates are allowed; context still decides among competitors. LearnedProposed from one model's own transcripts and accepted by you. Used only with that model.
    GenerateSends this speech model's raw transcripts, with the current dictionary as context, to the dictionary model you choose. It proposes new groups only; nothing is saved until you apply them. RefineSends each dictation's raw transcript beside the dictionary step's result, with the current dictionary. It proposes groups to add, revise or remove, judged on how the dictionary behaved; nothing is saved until you apply them. AgentsAgents you dictate to can post a confirmed correction to Dictum's local API. It arrives here as Pinned; remove it if they got it wrong. SizeLookup retains competing forms. Unusually complex overlaps are left unresolved; larger dictionaries are not guaranteed to be faster.

    Model
    Jev · TypeSafe
    A decision model that reads each transcript after the speech model and answers questions about it; it never writes text. On your own key, about $0.04 per million tokens: a dictation costs a fraction of a cent.
    Correction, filler reduction and formatting share the total wait, including retries. If correction fails, the original transcription is delivered. A filler-reduction or formatting failure keeps that stage’s input.

    Cloud speech sends audio to your selected provider. Dictionary builds send transcripts and dictionary contents to your chosen language model. Enabled Jev correction, filler reduction and formatting send text, proposed spans and relevant meanings to TypeSafe, even with local speech recognition. Temporary build transcripts are not saved by Dictum; remote retention depends on each provider.
