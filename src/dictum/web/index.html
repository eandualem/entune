Get started

Three steps, and every dictation lands here as text you can copy.

    The file is dictionary.json in Dictum's data folder. Heard phrases are whole words, matched regardless of case; the longest phrase wins.
    EntryA term as you spell it, what it means to you, and the phrases speech models write instead: Claude Code ← cloud code. Every heard phrase is fixed in every transcript afterwards. DescriptionWith Jev on (Settings › Providers), each match is decided in context from this description: Jeff becomes JEV in a note about the model and stays in a note about a person. PinnedEntered by you. Used with every model. Never changed by a machine. LearnedProposed from one model's own transcripts and accepted by you. Used only with that model.
    RefineSends this model's recent transcripts, with your pinned list as context, to the dictionary model set in Settings. You get a proposal, entries to add and to drop, and nothing is saved until you press Accept. AgentsAgents you dictate to can post a confirmed correction to Dictum's local API. It arrives here as Pinned; remove it if they got it wrong. SizeThere is no limit. The list is meant to grow, and matching stays fast however long it gets.
    Build from your audio

    Bring audio from Wispr Flow or a folder. Original audio stays on this Mac for reuse with another model. Fresh transcripts are used only for this build and are not saved to history.

    Wispr imports retained audio from this Mac and its local Flow backups. Folders support WAV, MP3, M4A, FLAC, OGG and WebM, up to 199 MB per file.

    Keep Dictum running until the proposal is ready. Closing the app discards build progress; your imported audio stays saved.
